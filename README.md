El objetivo de este proyecto es tener un control de los turnos asignados para una clinica, la interfaz esta diseñada para poder cargar 
datos de los pacientes y los medicos profesionales. A su vez asignar roles y usuarios para que puedan interactuar con dicho sistema.
Basicamente gestiona los horarios de los turnos, marcando los que están disponibles y los ocupados para que no exista una 
inconsisitenciaen los turnos generados. Estos datos se guardan en una base de datos, para consultar disponibilidad y que hoarios
por dia ya fueron ocupados. 
Esta diseñado en lenguaje Java 17 con Spring Boot, utilizando el ide Intelijj IDEA, sincronizado a una base de datos en HeidiSQL.
